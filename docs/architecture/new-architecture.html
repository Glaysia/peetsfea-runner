3. edtmgr 동작 & 타이밍

왜 필요한가

ansysedt는 켜고 끄는 비용이 매우 크고, 끄면 EDT 라이선스를 놓친다. edtmgr는 별도 시뮬이 아닌 관리용 pyaedt 세션을 상시 물고 있어 ansysedt를 warm으로 유지하고 라이선스 점유를 이어 간다.

  • acquire — 관리 점유만 잠깐 놓음(ansysedt는 살림) → {pid, grpc_port} 반환
  • 시뮬 pyaedt가 같은 ansysedt grpc에 접속·실행
  • done/release — 관리세션 재부착 → 다음 fixed toml 대기

시간 임계값

시점동작
~40분목표 — 마지막 패스 후 리포트 저장
60분시뮬 자체 abort → 마지막 완료 패스 리포트
65분edtmgr 백스톱 — pyaedt+ansysedt SIGKILL → 재기동

대여 중 ansysedt 사망 시 즉시 감지·재기동(해당 대여 실패 처리).

4. 자원 / 파일시스템 / 라이선스

  • /dev/shm, /tmp 사용 금지 → 잡 전용 job_tmpfs / job_disk
  • 잡 시작 시 /enroot/{USERNAME}_{SLURM_JOB_ID} 생성, 잡 종료 시 삭제
  • 라이선스는 충분 → 상한 미고려, edtmgr 관리세션으로 상시 점유만 유지
